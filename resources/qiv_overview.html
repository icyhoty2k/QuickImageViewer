Technical Overview — July 2026

QuickImageViewer (QIV)

A fast, minimal, GPU-accelerated image viewer for Windows built on Direct2D and WIC. Designed for speed, low memory overhead, and broad format support without external codec dependencies where possible.

Windows 10 / 11 C++23 Win32 / Direct2D / WIC Single EXE, no installer ~4 MB binary
Architecture

Renderer

Direct2D + D3D11. GPU bitmap cache. Fallback software GDI renderer for edge cases. Effects pipeline via ID2D1Effect graph (brightness, contrast, saturation, gamma, grayscale, sepia, invert, outline, threshold, solarize).

Decoding

Primary pipeline: WIC (Windows Imaging Component). Secondary pipeline: custom decoders in SimpleFormats.cpp for formats WIC doesn't cover. SVG via resvg (Rust, static lib).

Threading

Worker thread pool for background decode and preload. Atomic wantedIndex prevents stale frames. WM_QIV_REPAINT / WM_QIV_SVG_READY messages signal UI thread when decode completes.

Caching

GPU bitmap cache with configurable size. Preloads adjacent images in both directions. Cache window (F3) shows live occupancy and lets user inspect or evict entries.

DPI / HiDPI

Per-monitor DPI aware (V2). All layout, fonts, and hit areas scale via MulDiv against GetDpiForWindow. No layout assumptions at 96 DPI.

Persistence

Registry-backed settings. Folder history manager. Recent folders sorted by visit frequency and recency. Favorites system inside the history panel.

UI Panels
EXIF / Info
M
Floating panel showing full image metadata: file info, GPS coordinates with offline reverse geocoding (city, district, state, country, continent, capital, currency, phone prefix, timezone), camera make/model, capture settings (exposure, aperture, ISO, focal length, flash, white balance, metering, scene), and author/copyright. Click rows to copy. Action rows (map link) are clickable.
Directory
F5 / F6
Side panel showing all images in the current folder. Scrollable thumbnail list. Click to navigate. Syncs selection rectangle with current image. Up to N simultaneous instances for comparing folders. Spawnable from history panel (Shift+Enter).
Cache
F3 / F4
Shows live GPU bitmap cache occupancy. Displays cached images as thumbnails, total memory used, eviction status. Moveable. Lets user inspect what's preloaded.
History
Tab
Recent folder list sorted by visit frequency. Space toggles favorite status on a folder. Ctrl+Shift+Delete clears history, Ctrl+Alt+Shift+Delete clears favorites. Shift+Enter opens selected folder in a DirWnd instance.
Thumbnail Strip
auto
Horizontal thumbnail panel. Shows surrounding images in the playlist for quick navigation context.
Help
F1
Full keyboard shortcut reference. Ctrl+E exports all shortcuts to a text file. Scrollable, searchable by eye.

Offline Reverse Geocoding
Fully offline — zero network calls

GPS coordinates from EXIF are resolved to rich location data using GeoNames datasets compressed and embedded directly in the EXE as RCDATA resources.

ResourceSourceEntriesCompressedProvides
cities.bincities1000.txt170,387~2.5 MBCity name, lat/lon, timezone, admin codes
admin1.binadmin1CodesASCII.txt3,865~32 KBState / province names
admin2.binadmin2Codes.txt47,549~423 KBDistrict / county names
country.bincountryInfo.txt252~5 KBCountry, capital, continent, currency, phone prefix

Nearest city found via linear scan with cosLat longitude correction. All 4 datasets loaded and decompressed (zlib/miniz) lazily on first GPS lookup. Fields displayed: City, District, State, Country, Continent, Capital, Currency, Phone, Timezone.

JPEG 2000 decoder. Static, OPJ_STATIC defined.

OpenEXR decoder. Header-only (4 files + miniz.c).

zlib-compatible compression. Used for GeoNames resource decompression. Compiled as C file.
