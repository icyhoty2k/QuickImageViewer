A fast alternative to Windows Photos

Press the arrow key and the next picture is simply there. A free image viewer for Windows 10 and 11 in one portable executable — no installer, no account, no ads, no telemetry.

Photos is an app built for a library: an account, a cloud, an editor and a gallery. If what you actually do is open a folder and go through it, all of that sits between you and the next picture. QuickImageViewer is built for that one job.

Photos wins the editing row, honestly. QuickImageViewer is a viewer: it has non-destructive GPU effects and Ctrl+S bakes them into a copy, but there is no crop tool. Keep an editor for editing.

What you get that Photos does not have

  • Floating thumbnail strips — up to six at once, and they work as a small file manager: drag pictures between folders.
  • Cull mode — keep or reject with one key per picture, and the rejects move together at the end. How culling works →
  • Slideshow with GPU transitions, information overlays in nine slots — filename, zoom, dimensions, file size — and place names for GPS-tagged photos, worked out offline with no network.
  • Your phone as a remote or second screen through the free Android companion, qIV Remote — or as a photo frame your PC drives.

Making it the default viewer

Windows decides the default per file type. Right-click a .jpg, choose Open with → Choose another app, point it at QuickImageViewer.exe and tick Always use this app. Do the same once for .png, .heic and anything else you open often. To go back, choose Photos the same way.

Questions

What does it cost?

Nothing. QuickImageViewer is free and open source under the AGPL — no advertising, no telemetry, nothing to buy, no account.

Do I have to install it?

No. Download one file and run it; to remove it, delete the file. It is also on winget: winget install IcyHotY2K.QuickImageViewer. It keeps its settings in the registry by default — pass -config with a path to keep them in an .ini beside the executable instead.

Will it run on my PC?

Windows 10 or 11, 64-bit. Each release also carries a QuickImageViewer-LegacyCPU.exe for older processors.
