QuickImageViewer (qIV)

A blisteringly fast, GPU-accelerated native C++23 image viewer for Windows. Zero flicker, zero telemetry, ~7 MB portable executable.

Why QuickImageViewer?

Built for Speed

Unlike modern web-based electron wrappers, qIV is a pure native application. It uses a GPU bitmap cache to keep decoded images in VRAM, preloading in both directions on a background thread. The UI thread never blocks.

Hardware Accelerated

Built directly on top of Direct2D and the Windows Imaging Component (WIC). It achieves zero-flicker rendering and instantly falls back to GDI software rendering only when necessary.

Format Support

Native OS formats are handled by the zero-dependency Windows Imaging Component, while complex formats utilize highly optimized custom and static library decoders.

Core Features

Navigation & UI

  • Instant Startup: Hide to tray with Esc and recall instantly, process stays resident in RAM.
  • Thumbnail Strips: Scrollable, wrap-around thumbnail previews for cache, directory, and history.
  • Smart Navigation: Smart jump between first/last images, instant folder history toggling, and Find mode with wildcard support.
  • Overlay System: 9 independently configurable data slots rendered directly on the canvas.

Offline Reverse Geocoding

GPS coordinates in EXIF data are resolved to full location details (City, State, Country, Timezone) with zero network calls. A compressed zlib database of GeoNames data is embedded directly into the executable.

GPU Color Effects

Real-time, non-destructive image adjustments via the Direct2D effect graph. Bake and save directly to disk with Ctrl+S.

Command-Line & Kiosk Mode

qIV supports extensive CLI arguments for automation, slideshows, and locked-down kiosk environments.

QuickImageViewer.exe -dedicated -lock -fullscreen -slideshow -shuffle -slideshowInterval 8 -startFolder "D:\Ads"

Runs an isolated instance on a dedicated monitor, loops a shuffled slideshow every 8 seconds, and ignores all user mouse/keyboard input.

Architecture & Building

Written in C++23. Requires CMake and MSVC (Visual Studio 2022 or CLion). The threading model utilizes atomic indices and WM_QIV_REPAINT messages to synchronize the worker thread pool back to the UI thread seamlessly.

git clone https://github.com/icyhoty2k/QuickImageViewer.git
cd QuickImageViewer
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release
